FRANKLIN CHAPEL • CHURCH BOOTH GUIDE

Install the One Night of Revival package in OBS.

This guide creates a separate Revival scene collection, leaving the church’s Main OBS theme untouched.

OPEN REVIVAL PACKAGEDOWNLOAD OFFLINE PACKAGEPRINT GUIDE
Before starting: In OBS, choose Scene Collection → Export and save a backup of the current church collection. Do not delete the Main OBS collection.

1. Prepare OBS

1

Create a separate collection

Choose Scene Collection → New and name it One Night of Revival.

2

Confirm video size

Open Settings → Video. Set Base Canvas and Output Resolution to 1920 × 1080.

3

Use hosted Browser Sources

The hosted URLs below receive design updates automatically. A downloaded local copy is available as a backup.

4

Preserve camera and audio

Add the church camera and microphones to the new Live Worship scene. Do not remove them from the Main collection.

2. Create the Revival scenes

For every row, create a new OBS scene. Inside it, choose Sources → + → Browser, paste the URL, and set Width 1920 and Height 1080.

4. Announcement audio setup

  1. Open the Announcements Browser Source properties and enable Control audio via OBS.
  2. In the Audio Mixer, confirm the Browser Source is not muted.
  3. To hear it in the booth, open Advanced Audio Properties and select Monitor and Output.
  4. If only livestream viewers need to hear it, Monitor Off is acceptable; the sound still goes to the stream.
  5. Enable Shutdown source when not visible and Refresh browser when scene becomes active so the reel restarts cleanly.

Final booth test

  • Click through every scene before service.
  • Confirm the announcement music and every voiceover can be heard.
  • Confirm overlays have transparent camera areas.
  • Record a 30-second test and play it back before going live.
