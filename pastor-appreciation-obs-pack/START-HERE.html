Quick start
  1. Unzip the pack and open OBS. Choose Scene Collection → Import, select obs-scene-collection/Pastor-Appreciation-OBS.json, and import it.
  2. Select Franklin Chapel • Pastor Appreciation • Oct 25 2026 from the Scene Collection menu. This creates a separate collection.
  3. Open the last scene, CAMERA + AUDIO • Connect Once. Add your church camera above the standby background. Use Transform → Fit to Screen. Add the church audio feed here if the camera does not carry it. Every live scene shares this camera-and-audio scene.
  4. Confirm a 1920 × 1080 canvas in Settings → Video. Check the camera and sound in Live Worship — Clean before the service.

Which scene to use

  • Before worship: Event Flyer, Welcome Home, Worship Begins Soon, or Sunday Announcement Reel.
  • At 9:55 AM or 2:55 PM: Five Minute Countdown starts fresh at 05:00. It stays at “Worship begins now” when time runs out.
  • During worship: Live Worship — Clean keeps the camera clear with a small event graphic.
  • Introducing someone: choose the Pastor, First Lady, 10 AM Dr. Carlos Perkins, or 3 PM Pastor Darrell “BJ” Gibson scene. The title animates in and stays for 15 seconds, then clears automatically. Switch away and back to show it again.
  • Offering: use Ways to Give — Full Screen, or Live + Ways to Give for the camera with a giving banner.
  • Closing: Thank You for Worshiping. Use Be Right Back for an intermission.

Sound for videos

The Sunday Announcement Reel and BIG-Z TV browser sources have Control audio via OBS enabled. Their audio appears in the OBS mixer. Monitoring is off to prevent a second local playback; stream/recording audio is enabled. Check the meters before service. The remaining graphics are silent.

The bundled Sunday reel contains only Pastor Appreciation Sunday, Fall Fest, Breast Cancer Awareness Month, Clergy Appreciation Month, and BIG-Z TV. It is a fixed Sunday edit, about 2 minutes 20 seconds. BIG-Z TV is also available separately.

Using the pack without internet

All artwork, graphics, and MP4s are included. After extracting the ZIP, run Create-Offline-Collection.command on Mac (requires Python 3) or Create-Offline-Collection.cmd on Windows (uses built-in PowerShell). This creates Pastor-Appreciation-OFFLINE.json beside the guide, with the correct paths for that computer. Import that file instead. If you move the extracted folder, run the helper again and import the refreshed file.

You can also add any numbered HTML file manually as a Browser Source → Local file, at 1920 × 1080. Enable Shutdown source when not visible and Refresh browser when scene becomes active. Put transparent overlays above the camera. For video pages, enable Control audio via OBS.

Custom scripture title

In the preview page, expand Customize the scripture title, enter the reference and supporting line, then click Preview. Open the custom scene and copy its address into the PA • Scripture reading title browser source in OBS. No Bible text or sermon title is assumed.

To keep a speaker title visible, add &hold=1 to its hosted browser address. For offline use, use the supplied transparent PNG title as an Image Source above the camera.

Included files

The numbered HTML scenes, matching transparent SVG and PNG titles, full-screen flyer, two MP4s, an OBS import, and offline helpers. Keep the assets folder next to the HTML files. No additional OBS plugins are required.
