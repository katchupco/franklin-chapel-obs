Open START-HERE.html for the illustrated setup guide.
Open index.html to preview the scenes.

OBS QUICK START
Scene Collection > Import > obs-scene-collection/Pastor-Appreciation-OBS.json
Then select Franklin Chapel • Pastor Appreciation • Oct 25 2026.

Connect your camera and church audio once in CAMERA + AUDIO • Connect Once.
All live scenes reuse that shared scene. Fit the camera to the 1920x1080 canvas.

The main import uses the published GitHub pages, so it works without changing paths.
For an offline import, run Create-Offline-Collection.command (Mac, Python 3 required)
or Create-Offline-Collection.cmd (Windows, built-in PowerShell).
Import the resulting Pastor-Appreciation-OFFLINE.json.
Keep this folder in place after creating the offline import.

Speaker titles remain for 15 seconds, then clear automatically.
The countdown resets each time that scene becomes active.
The two video scenes route audio into the OBS mixer.
No extra OBS plugins are needed.
