Protect the church setup first: In OBS, choose Scene Collection → Export and save the current collection. The recommended method below adds only the new sources and keeps existing cameras, microphones, and scenes.

Recommended: update the existing collection manually

1

Add the narrated reel scene

Create a scene named 04C • Narrated Announcement Reel. Add a Browser Source named FC • Narrated Announcement Reel.

2

Use this reel URL

https://katchupco.github.io/franklin-chapel-obs/04c-announcement-reel.html

Set Width 1920, Height 1080, enable Control audio via OBS, Shutdown when not visible, and Refresh when active.

3

Add the giving overlay

Open 02 • Live Worship. Add a Browser Source named FC • Giving Overlay using:

https://katchupco.github.io/franklin-chapel-obs/05a-giving-overlay.html

4

Keep it hidden until giving

Set the giving source to 1920 × 1080 and place it above the camera. Leave its eye icon off. Turn it on during giving and off afterward.

Correct source order in 02 • Live Worship

OBS displays sources from top to bottom. Arrange the new source like this:

TOP: FC • Giving Overlay — normally hidden FC • Controlled Lower Third FC • Center Scripture Overlay FC • Live Frame BOTTOM: Church camera

Announcement sound check

  1. Switch to 04C • Narrated Announcement Reel.
  2. Confirm its Browser Source appears in the Audio Mixer and is not muted.
  3. Open Advanced Audio Properties. Choose Monitor and Output if the booth operator needs to hear it.
  4. Let the first slide play through one complete voiceover and transition.
  5. If sound does not start, open Browser Source Properties and select Refresh cache of current page.

Optional: import a fresh updated collection

Use this only if you want a separate fresh collection. Importing does not update the currently open collection in place.
  1. Download and unzip the updated package using the button at the top.
  2. In OBS, choose Scene Collection → Import.
  3. Select Franklin-Chapel-Cinematic-Noir.json from the OBS Scene Collections folder.
  4. Switch to the imported Franklin Chapel • GitHub Hosted collection.
  5. Reconnect the church camera and confirm microphones before using it live.

What the update includes

  • 04C • Narrated Announcement Reel: nine event slides in date order, voiceovers, background music, and automatic music ducking.
  • 05A • Giving Overlay: transparent lower overlay with Cash App, PayPal, and online giving.
  • The Giving Overlay is included as a hidden source inside 02 • Live Worship in the fresh downloadable collection.
  • Existing announcement, offering, camera-announcement, and custom-video scenes remain available.

Final safety check

  • Make a short local recording before Sunday.
  • Check that the giving overlay does not cover faces or captions.
  • Verify all narration is present in the recording.
  • Keep the exported backup until the updated collection has completed a full service successfully.
