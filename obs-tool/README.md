# Franklin Chapel GitHub-Hosted OBS Controls

No local server is required.

## Custom Browser Docks

- Lower thirds:
  `https://katchupco.github.io/franklin-chapel-obs/obs-tool/control-panel.html`
- Scripture:
  `https://katchupco.github.io/franklin-chapel-obs/obs-tool/scripture-control.html`

## Browser Sources

- Lower-third overlay:
  `https://katchupco.github.io/franklin-chapel-obs/obs-tool/on-air-overlay.html`
- Scripture overlay:
  `https://katchupco.github.io/franklin-chapel-obs/obs-tool/scripture-overlay.html`
- Full-screen Scripture:
  `https://katchupco.github.io/franklin-chapel-obs/03-scripture.html`

Set every overlay Browser Source to **1920 × 1080**, leave **Local file**
unchecked, and keep overlays above the live camera.

All control and overlay pages use the same GitHub origin, allowing the docks to
communicate with the on-screen sources and restore the most recent state.
